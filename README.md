# 经经有条

面向全国中医药经典能力等级考试三级的本地学习辅助应用。React、TypeScript、Vite、Dexie；无账号和服务端，学习记录保存在当前浏览器的 IndexedDB。

## 当前内容与使用

截至2026-10-21，完整课程对应2026累计考纲的712条要求、106个归并章节。目录共2484题，1853题可用于章节学习，631题隔离。教材对照和AI交叉核验不等于独立教师审定、考试难度校准或完整能力覆盖。

- 从“今天 → 开始或继续今日领学”进入完整课程：阅读、闭卷回忆、关联练习、核对、错因订正和至少24小时后复测。回忆与答题时隐藏资料，书面题人工核对、不自动评分。
- 同页“我的30天学习计划”显示30天总览、每日进度及剩余安排，支持按预算重排，保留已完成记录。
- 章节练习与整套演练保留出处和核验边界；仅学习题不进入整卷，争议题及相关题族按规则过滤。
- “我的”提供从头开始、冲刺及切换前快照恢复。冲刺保留未完成小段，先保存并暂放小段后可查看第25天安排。
- “经典”另有40个原文记忆专项单元；完整712条主线位于 `/course`。

伙伴、茶杯兔与嫩芽为生成图片；应用界面不使用原始参考照片。

## 时间与测评边界

20分钟是一个小段，不是全天任务。仅按每条阅读和回忆5分钟估算，712条首轮共3560分钟，练题、深入理解与复习另计。预算不足时应延长计划或增加学习时间，不能宣传“每天20分钟、30天学完”或“跟着学必过”。

最终长期模拟修复了复习积压挤掉新内容的问题，按新内容实际用时和任务名额预留空间，展示顺序仍优先复习。5组30天合成情景持续推进；合成答案不是实际学习效果。

整套演练为91题、100分钟，能力题须人工复核。完整A3共用病例题组仿真、累计等级30/30/40及难度6/2/2校准尚未完成，不能称官方仿真或考试通过率预测。

## 本地运行

需要Node.js和npm。推荐 Node.js 24。发布流程使用锁定依赖独立安装并构建。

```powershell
npm.cmd ci
npm.cmd run dev
```

打开 http://127.0.0.1:5173/#/today ，填写伙伴名字，再从今天进入领学。当前本地学习包内置，无需手动导入。

```powershell
npm.cmd run build
npm.cmd run preview -- --host 127.0.0.1 --port 5176
```

生产预览打开 http://127.0.0.1:5176/#/course 。首次联网并完成缓存后可离线使用，开发服务不注册Service Worker。不要直接双击 `dist/index.html`。

学习记录按浏览器、端口和域名隔离。换浏览器或地址前在“我的”导出存档，再在目标地址恢复。学习包与个人存档用途不同，存档不会上传服务器。

## 验证与复现

同时启动开发服务5185、生产预览5176及当前5173版本，再运行：

```powershell
npx.cmd tsc -b
node tests/run-current-audit.mjs
```

当前57项回归通过；其中 `tests/course-coach-longitudinal.ts` 对真实712条目录运行5组30天调度模拟。浏览器验收覆盖资料隐藏、错因订正、隔天复测、草稿恢复、每日进度、重排、重启/冲刺、交卷、离线与过期写入保护。测试仅用隔离存档，不修改真实用户记录或电脑时钟。最新证据位于上级 `verification/current-audit/`，旧阶段报告保留历史结论。

部分专业核验测试依赖本目录外 `work/` 的冻结输入及本机原题表；只复制本目录不能复现全部核验。历史测试原样保留，依赖外部工作输入的历史核验不属于公开包的默认测试；发布与日常测试使用下述不依赖外部资料的 5 项回归。

## 公开网页与开源部署

在线使用：[开始学习](https://weiruijiao0.github.io/jingjing-youtiao/#/today)。无需注册，打开即可使用。部署与验收记录见 [发布验收](docs/DEPLOYMENT.md)。

所有人打开已部署的网页即可开始使用，无需注册账号。该版本没有账号密码登录、云端同步或后台服务。每个人的记录分别保存在自己当前设备、浏览器和网站地址下，彼此不共享。

现有页面、运行代码、题库与学习资料完整保留。发布支持文件仅增加自动构建、部署、许可和说明。代码使用 MIT 许可证；资料授权和原始署名见 NOTICE.md。

仓库内已包含 GitHub Pages 自动发布流程。推送到 main 分支后，流程会独立安装依赖，运行发布回归、构建成品并部署到 GitHub Pages。仓库 Settings → Pages → Build and deployment 的 Source 选择 GitHub Actions。使用相对资源地址及哈希路由，既支持项目网址，也支持自定义域名。

```sh
npm ci
npm test
npm run build
npm run preview
```

`npm test` / `npm run test:release` 运行公开包可独立复现的 5 项回归：712 条课程与页图链接、回忆队列、91 题试卷组装与人工评分保护、领学闭卷与存档、5 组连续 30 天调度。它们验证软件行为，不证明通过率。完整 57 项历史验收的外部输入未复制到公开包；`npm run test:historical` 保留历史入口。

发布流程另外在仓库子路径下进行 5 项浏览器验证，覆盖进入领学、30 天进度、资料图片、闭卷草稿恢复、离线缓存、经典和重启/冲刺入口。手动运行需先构建，再执行 `npx playwright install chromium` 与 `npm run test:pages`。Windows 已安装 Edge 时，也可设置 `PLAYWRIGHT_CHANNEL=msedge` 使用它验证。

首次打开会缓存学习资料。首次加载需要联网，资料较多，请等待加载完成；网页可正常打开后再考虑离线使用。更换设备、浏览器或网址前，请先在“我的”导出学习存档，并在新地址恢复。
